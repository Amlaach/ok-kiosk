# OK Kiosk

**OK Kiosk** היא תוכנת קיוסק ונעילת מחשב עצמאית ל-Windows (בקוד פתוח), המיועדת להפוך מחשב רגיל למחשב מנוטר ומאובטח שבו ניתן להריץ רק תוכנות ותיקיות שאושרו מראש על ידי המנהל.

> תוכנת הקיוסק קיימת בזכות פרויקט **[אחת שאלתי](https://github.com/achat-shaalti/achat-shaalti)**.

> [!WARNING]
> **אזהרה חשובה — אין לבצע ניסויים ישירות על המחשב האישי!**
> תוכנת קיוסק ונעילה משנה הגדרות מערכת פעילות (חסימת Task Manager, סגירת `explorer.exe`, חסימת קיצורי מקלדת, ושירות `SYSTEM` בגרסה המוקשחת).
> **אל תריץ ואל תבדוק את מצב הנעילה ישירות על המחשב האישי/העיקרי שלך!**
> יש לבדוק את התוכנה אך ורק בתוך **מכונה וירטואלית (VM)** או **Windows Sandbox** לפני התקנה על מחשב ייעודי.

## ארכיטקטורה והפרדת אבטחה
הפרויקט מחולק לשני מאגרים נפרדים:
- **`Amlaach/ok-kiosk` (ציבורי / קוד פתוח):** ממשק הקיוסק (Launcher), הגדרות מערכת, ניהול תוכנות ותיקיות, מגש המערכת, חוזי האבטחה (`OkKiosk.Contracts`), ובדיקות.
- **`Amlaach/ok-kiosk-security` (פרטי / בינארי בלבד):** מנועי ההקשחה, האנטי-עקיפה, שירות ה-SYSTEM, חתימות והגנות מערכת ההפעלה. בזמן יצירת Release רשמי, תהליך ה-CI מושך את `OkKiosk.Security.dll` באמצעות מפתח SSH ייעודי (Deploy Key) ואורז את הגרסה המלאה.

תורמים חיצוניים יכולים לבנות ולהריץ את הפרויקט בקוד פתוח (מול מימוש `OpenSecurityStub` מובנה לצורכי פיתוח UI), ללא צורך בגישה לבינארי ההקשחה הפרטי.

## מבנה התיקיות
- `src/OkKiosk.Contracts/` — ממשקים וחוזים משותפים (`IKioskSecurityProvider` ועוד)
- `src/OkKiosk.App/` — אפליקציית הקיוסק הראשית (WinForms / .NET 8)
- `tests/OkKiosk.Tests/` — בדיקות יחידה
- `scripts/fetch-security.ps1` — משיכת הבינארי המאובטח מקומית באמצעות SSH ייחודי
- `security/` *(ב-`.gitignore`)* — מאגר גיט נפרד לחלוטין עבור `Amlaach/ok-kiosk-security`
- `vendor/security/` *(ב-`.gitignore`)* — מיקום ה-DLL הבינארי של האבטחה בזמן בנייה

## בנייה ובדיקה בטוחה
```powershell
dotnet build OkKiosk.sln
dotnet test OkKiosk.sln
```
לבדיקת ריצה של ממשק הקיוסק והנעילה מומלץ להעתיק את תוצר הבנייה (`publish`) לתוך **Windows Sandbox** או מכונה וירטואלית (Hyper-V / VirtualBox).
